## 開始專注

可以從主視窗、系統匣選單或全域快速鍵開始。計時器會在三個階段之間移動：

- **專注** — 預設 25 分鐘。
- **短休** — 預設 5 分鐘。
- **長休** — 預設 15 分鐘，每四輪專注後出現。

每個時長和長休間隔都可以在[設定](../settings/)裡修改。暫停和繼續會保留剩餘時間；截止時間保存在 Rust 核心，隱藏視窗不會讓計時停止。

## 操作

| 操作 | 位置 |
| --- | --- |
| 開始或暫停 | 主視窗、系統匣選單、`Ctrl+Alt+P`（macOS 為 `Cmd+Option+P`） |
| 跳過目前階段 | 系統匣選單、`Ctrl+Alt+S`（macOS 為 `Cmd+Option+S`） |
| 重設目前工作階段 | 主視窗或系統匣選單 |
| 顯示或隱藏懸浮球 | 系統匣選單、`Ctrl+Alt+O`（macOS 為 `Cmd+Option+O`） |
| 開啟歷史 | 主視窗 → **歷史** |

跳過專注會記為「已跳過」，重設會記為「已重設」。任何結果都不會被悄悄丟棄。

## 懸浮倒數

懸浮視窗是一個始終置頂的小視窗。滑鼠不靠近時點擊穿透，不會擋住下面的工作。

- 把滑鼠移到水滴或倒數上，它就會接收點擊。
- 按住拖曳可以移動。位置依顯示器記住。
- 不拖曳、直接點擊會開啟主視窗。
- 右鍵開啟懸浮視窗選單。
- 可以從系統匣選單或設定裡隱藏。

首次啟動時懸浮視窗在左下角。如果原本的顯示器中斷，Break 會退回主顯示器，並在顯示器恢復後回到原位置。

Wayland 不允許可靠的絕對定位。在 Wayland 工作階段裡位置由合成器決定，點擊穿透也可能無法使用。完整體驗請使用 X11。

## 休息卡片

每個階段結束時，Break 可以彈出應用程式內小卡片，而不是作業系統通知。

- **專注結束：** 開始休息、延後五分鐘、跳過，或關閉卡片。
- **休息結束：** 開始下一輪專注；如果專注已經自動開始，卡片會自行關閉。
- **倒數結束：** 關閉，或按同樣時長再來一次。

提醒與提示音有獨立開關。關閉提醒會隱藏所有卡片並靜音，但計時器、系統匣和懸浮視窗繼續運作。提醒關閉時，「預覽」按鈕無法使用。

## 睡眠與喚醒

如果電腦在截止時間前進入睡眠，Break 不會一次彈出一堆卡片。它會顯示「歡迎回來」卡片，說明階段在離開期間已經結束。你可以開始休息或重設工作階段；錯過的循環不會補播。

## 歷史

每次專注、休息和倒數都會保存在本地。開啟**歷史**可以依日期查看完成、跳過、重設和中斷的紀錄。使用**匯出**產生帶排版的 `.xlsx` 活頁簿，包含摘要、每日和明細工作表。
