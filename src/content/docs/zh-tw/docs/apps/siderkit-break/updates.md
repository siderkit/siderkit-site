## Windows

Break 每六小時在背景檢查一次更新。開啟**設定 → 更新**並點選**檢查更新**也會立即檢查。

有新版本時，主視窗會出現一條非模態更新列。你可以：

- **下載**簽署安裝檔。更新列和設定裡都會顯示進度，並可取消。
- 下載完成後**重新啟動安裝**。Break 會重新啟動進入安裝程式，不會在背景靜默安裝。
- **跳過此版本**，不再看到這個版本；之後可以在設定裡恢復。
- **延後 24 小時**，適合手頭正忙的時候。

安裝前會用 minisign 公開金鑰驗證安裝檔。主下載站無法使用時，應用程式會退回 GitHub 的發布清單。

設定 → 更新、設定 → 關於、說明 → 關於使用同一個版本與狀態區塊。有更新可下載或可安裝時，說明圖示會顯示紅點；關閉更新列也會讓紅點消失。

## macOS 與 Linux

macOS 與 Linux 版本需要手動下載。**檢查更新**會開啟 GitHub 發布頁；Break 不會替換已安裝的應用程式。

- macOS：下載 Universal DMG，把應用程式拖進「應用程式」。在設定 Developer ID 之前，建置未簽署。
- Linux：下載與你的發行版相符的 deb、rpm 或 AppImage。

## 更新失敗時

- 下載失敗可以在更新列或設定裡重試。
- 簽章驗證失敗時，Break 會拒絕安裝。請從官方發布頁重新下載，並核對 SHA-256。
- 安裝程式無法啟動時，完全結束 Break，再手動執行下載好的安裝檔。

每個版本的說明在[版本紀錄](../../../../apps/siderkit-break/changelog/)。
