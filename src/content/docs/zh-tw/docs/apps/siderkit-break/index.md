Siderkit Break 是一款不擋路的小型專注計時器。它維持輕緩的節奏，用懸浮倒數顯示剩餘時間，並提醒你起身看看遠方。

本文件對應 Siderkit Break 1.0。應用程式介面支援 30 種語言；文件提供英文、簡體中文和繁體中文。

## 它能做什麼

- 執行專注、短休和長休循環，所有時長都可以修改。
- 計時由 Rust 核心負責，視窗隱藏時仍然準確。
- 顯示始終置頂的倒數，滑鼠不靠近時點擊穿透。
- 每個階段結束彈出一張小卡片，可延後、跳過或關閉。
- 把完成、跳過和中斷的專注紀錄存進本地 SQLite 資料庫。
- 匯出帶排版的 `.xlsx` 活頁簿，包含摘要、每日和明細工作表。
- 無需帳號，也不同步。只有更新檢查和選用的匿名安裝計數會連網。

## 範圍說明

Break 是專注計時器，不是任務管理器。它不包含待辦、筆記、專案、帳號、同步、團隊、外掛或 AI 功能。
