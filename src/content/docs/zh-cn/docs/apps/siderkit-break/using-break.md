## 开始专注

可以从主窗口、托盘菜单或全局快捷键开始。计时器会在三个阶段之间移动：

- **专注** — 默认 25 分钟。
- **短休** — 默认 5 分钟。
- **长休** — 默认 15 分钟，每四轮专注后出现。

每个时长和长休间隔都可以在[设置](../settings/)里修改。暂停和继续会保留剩余时间；截止时间保存在 Rust 核心，隐藏窗口不会让计时停止。

## 操作

| 操作 | 位置 |
| --- | --- |
| 开始或暂停 | 主窗口、托盘菜单、`Ctrl+Alt+P`（macOS 为 `Cmd+Option+P`） |
| 跳过当前阶段 | 托盘菜单、`Ctrl+Alt+S`（macOS 为 `Cmd+Option+S`） |
| 重置当前会话 | 主窗口或托盘菜单 |
| 显示或隐藏悬浮球 | 托盘菜单、`Ctrl+Alt+O`（macOS 为 `Cmd+Option+O`） |
| 打开历史 | 主窗口 → **历史** |

跳过专注会记为“已跳过”，重置会记为“已重置”。任何结果都不会被悄悄丢弃。

## 悬浮倒计时

悬浮窗是一个始终置顶的小窗口。鼠标不靠近时点击穿透，不会挡住下面的工作。

- 把鼠标移到水滴或倒计时上，它就会接收点击。
- 按住拖动可以移动。位置按显示器记住。
- 不拖动、直接点击会打开主窗口。
- 右键打开悬浮窗菜单。
- 可以从托盘菜单或设置里隐藏。

首次启动时悬浮窗在左下角。如果原来的显示器断开，Break 会退回主显示器，并在显示器恢复后回到原位置。

Wayland 不允许可靠的绝对定位。在 Wayland 会话里位置由合成器决定，点击穿透也可能不可用。完整体验请使用 X11。

## 休息卡片

每个阶段结束时，Break 可以弹出应用内小卡片，而不是操作系统通知。

- **专注结束：** 开始休息、推迟五分钟、跳过，或关闭卡片。
- **休息结束：** 开始下一轮专注；如果专注已经自动开始，卡片会自行关闭。
- **倒计时结束：** 关闭，或按同样时长再来一次。

提醒与提示音有独立开关。关闭提醒会隐藏所有卡片并静音，但计时器、托盘和悬浮窗继续工作。提醒关闭时，“预览”按钮不可用。

## 睡眠与唤醒

如果电脑在截止时间前进入睡眠，Break 不会一次弹出一堆卡片。它会显示“欢迎回来”卡片，说明阶段在离开期间已经结束。你可以开始休息或重置会话；错过的循环不会补播。

## 历史

每次专注、休息和倒计时都会保存在本地。打开**历史**可以按天查看完成、跳过、重置和中断的记录。使用**导出**生成带排版的 `.xlsx` 工作簿，包含汇总、每日和明细工作表。
