## Windows

Break 每六小时在后台检查一次更新。打开**设置 → 更新**并点击**检查更新**也会立即检查。

有新版本时，主窗口会出现一条非模态更新条。你可以：

- **下载**签名安装包。更新条和设置里都会显示进度，并可取消。
- 下载完成后**重启安装**。Break 会重启进入安装程序，不会在后台静默安装。
- **跳过此版本**，不再看到这个版本；之后可以在设置里恢复。
- **推迟 24 小时**，适合手头正忙的时候。

安装前会用 minisign 公钥校验安装包。主下载站不可用时，应用会回退到 GitHub 的发布清单。

设置 → 更新、设置 → 关于、帮助 → 关于使用同一个版本与状态区块。有更新可下载或可安装时，帮助图标会显示红点；关闭更新条也会让红点消失。

## macOS 与 Linux

macOS 与 Linux 版本需要手动下载。**检查更新**会打开 GitHub 发布页；Break 不会替换已安装的应用。

- macOS：下载 Universal DMG，把应用拖进“应用程序”。在配置 Developer ID 之前，构建未签名。
- Linux：下载与你的发行版匹配的 deb、rpm 或 AppImage。

## 更新失败时

- 下载失败可以在更新条或设置里重试。
- 签名校验失败时，Break 会拒绝安装。请从官方发布页重新下载，并核对 SHA-256。
- 安装程序无法启动时，完全退出 Break，再手动运行下载好的安装包。

每个版本的说明在[版本记录](../../../../apps/siderkit-break/changelog/)。
