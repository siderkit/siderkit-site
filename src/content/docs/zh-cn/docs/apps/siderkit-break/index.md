Siderkit Break 是一款不挡路的小型专注计时器。它维持轻缓的节奏，用悬浮倒计时显示剩余时间，并提醒你起身看看远处。

本文档对应 Siderkit Break 1.0。应用界面支持 30 种语言；文档提供英文、简体中文和繁体中文。

## 它能做什么

- 运行专注、短休和长休循环，所有时长都可以修改。
- 计时由 Rust 核心负责，窗口隐藏时仍然准确。
- 显示始终置顶的倒计时，鼠标不靠近时点击穿透。
- 每个阶段结束弹出一张小卡片，可推迟、跳过或关闭。
- 把完成、跳过和中断的专注记录存进本地 SQLite 数据库。
- 导出带排版的 `.xlsx` 工作簿，包含汇总、每日和明细工作表。
- 无需账号，也不同步。只有更新检查和可选的匿名安装计数会联网。

## 范围说明

Break 是专注计时器，不是任务管理器。它不包含待办、笔记、项目、账号、同步、团队、插件或 AI 功能。
